# 🎓 AI Campus Connect

AI Campus Connect is a smart AI-powered campus platform that helps students access campus information, academic support, announcements, and student services in one place.

## ✨ Features

- 🤖 AI Assistant
- 🏫 Campus Information
- 📢 Announcements
- 📚 Academic Support
- 💬 Interactive User Interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Artificial Intelligence
